### Бизнес-требования

#### TR-001: Регистрация и аутентификация

**Функционал:**
- Регистрация/авторизация
- Смена/восстановления пароля
- Вход в аккаунт по ссылке из почты?
- Восстановление пароля происходит через письмо отправляемое на электронную почту

**Реализация:**
- Регистрация пользователя через Keycloak
- Авторизация по OAuth2/OIDC flow
- Распределенная сессия в Redis (Spring session)
- Токен-базированая авторизация API (JWT token)
- Смена пароля через Keycloak

#### TR-002: Профиль пользователя

**Атрибуты профиля:**
- Имя
- Био
- Аватар
- Список любимых композиций/плейлистов (витрина)

**Функционал:**
- CRUD профиля (имя, био, аватар, витрина)

#### TR-003: Композиции, Плейлисты

**Атрибуты композиции:**
- Основные данные
	- Название
	- Главные исполнители
	- Приглашенные исполнители
	- Жанры
- Создатели
	- Композитор
	- Автор текста
	- Продюсер, звукорежиссер
- Дополнительные данные
	- Обложка
	- Теги
	- Текст (может быть синхронизирован)

**Атрибуты плейлистов:**
- Основные данные
	- Название
	- Теги
	- Видимость (публичный/приватный)
	- Список композиций
- Дополнительные данные
	- Обложка
	- Описание

**Функционал:**
- CRUD плейлистов
- Копирование чужих публичных плейлистов
- Создание плейлистов через синтез существующих
- Пользователь может загрузить одну или несколько композиций за раз, редактируя атрибуты

#### TR-004: Шаринг композиций, плейлистов

**Функционал:**
- Пользователь может поделиться плейлистом/композицией ссылкой (QR/link) или с конкретным пользователем

#### TR-005: Социальные функции

**Функционал:**
- Отправка приглашения в друзья
- Принятие/отклонения приглашения
- Удаление друзей
- Возможность скрыть свой профиль (будет отображаться только аватар и имя)
- Скрыть свой текущий статус (онлайн/офлайн, что проигрывается на текущий момент)

#### TR-006: Статистика пользователя

**Функционал:**
- Статистика прослушивания по композициям/плейлистам

#### TR-007: Воспроизведение композиций/плейлистов

**Функционал:**
- При начале прослушивания формируется очередь композиций

#### TR-008: Полнотекстовый поиск

**Функционал:**
- Поиск публичных плейлистов/композиций по названию, описанию, тегам

**Реализация:**
- PostgreSQL Full-Text Search
- Индексирование полей: название, автор, описание, теги

#### TR-009: WebSocket уведомления

**Функционал:**
- Push-уведомления через WebSocket

**Типы уведомлений:**
- Приглашение в друзья
- Шаринг плейлистов/композиций
- Публикация новых публичных плейлистов от друзей

#### TR-010: gRPC API

gRPC-интерфейс для взаимодействия между сервисами (ProtoBuff)

#### TR-011: Админ-панель

**Функционал:**
- Список пользователей (активация/деактивация)
- Удаление/блокировка плейлистов/композиций
- Статистика: кол-во пользователей, плейлистов, композиций, запросов
- Интеграция с Prometheus/Grafana

#### TR-012: Мониторинг

**Метрики Prometheus:**
- HTTP requests rate/latency
- JVM metrics
- БД-коннекшны
- Kafka consumer lag
